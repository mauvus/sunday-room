SUNDAY ROOM · Web Edition

Static website. Upload all files in this folder to any HTTPS static hosting.

Important:
- Keep the audio/ folder next to index.html.
- The QR code on the result poster uses window.SUNDAY_ROOM_SHARE_URL when defined; otherwise it uses location.href.
- For the final public site, set window.SUNDAY_ROOM_SHARE_URL in app.js only if you want a fixed canonical URL.
- Audio starts from the user's tap on the Start button, which is the safest cross-browser pattern for mobile autoplay policies.
